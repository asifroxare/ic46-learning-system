# IC-46 Interactive Learning System & Simulator — Project Master Document

## 1. Project Overview & Architecture
* **Repository Path:** `C:\Aasif\ic46-learning-system\`
* **Format:** Self-contained single-page web application (`index.html`) using Tailwind CSS CDN and Chart.js.
* **Core Philosophy:** Simulator-First Interactive Experience. Learners master every concept through interactive micro-bites, state-driven transaction sandboxes, and diagnostic mistake-trapping questions—**no raw textbook filler**.

---

## 2. The Standard 3-Part Unit Architecture
Every unit in the 19-unit curriculum must be built with three distinct, interactive components:

1. **Part 1: Learn Concepts (Micro-Bites)**
   * Granular, interactive cards covering 100% of the syllabus points, statutory sections, formulas, and definitions without requiring the textbook.
2. **Part 2: Interactive Sandbox (Apex Shield Insurance Co. Simulator)**
   * State-driven event decision tree with a live reactive Balance Sheet/P&L ledger meter (`cash`, `liabilities`, `equity`, `revenue`, `expenses`, `score`).
   * Dynamic mathematical mutations verifying $Assets = Liabilities + Capital$ on every choice.
3. **Part 3: Diagnostic Exam & Misconception Bank**
   * 10 to 15 exam-standard scenario MCQs per unit with instant rationale and diagnostic misconception codes (`MIS_*`).
